# PixelKit

<div align="center">

**استودیوی تصویر در مرورگر** — تبدیل، فشرده‌سازی، تغییر اندازه، فیلتر و واترمارک، بدون یک بایت آپلود.

[نشانی زنده](https://pouryaaryanpour.github.io/pixelkit/)

</div>

---

## چه کاری انجام می‌دهد

| قابلیت | توضیح |
|---|---|
| تبدیل HEIC / HEIF | رمزگشایی کامل فرمت‌های آیفون و مک به JPG، PNG یا WebP |
| فشرده‌سازی | کنترل کیفیت و ابعاد؛ حالت خودکار سبک‌ترین خروجی بین WebP و JPG را انتخاب می‌کند |
| تغییر اندازه | ۱۲ پیش‌تنظیم شبکه‌های اجتماعی + عرض/ارتفاع دلخواه |
| برش و کشش | پر کردن و برش مرکزی، جا دادن با حاشیه، یا کشیدن بدون تغییر نسبت |
| چرخش و برگرداندن | چرخش ۹۰ درجه‌ای و آینه‌ای بدون افت کیفیت |
| فیلتر | روشنایی، کنتراست، اشباع، محو‌شدگی، فام، سیاه‌وسفید، سپیا، معکوس + شارپ الگوریتمی |
| واترمارک | متن با اندازه، رنگ، شفافیت و ۹ موقعیت مختلف |
| پالت رنگ | استخراج رنگ‌های غالب تصویر با یک کلیک کپی |
| مقایسه | دسته‌کشیدنی بین تصویر اصلی و خروجی |
| پردازش دسته‌ای | تا ۵۰ فایل در هر نوبت، با خروجی ZIP |
| حذف EXIF / GPS | خروجی از نو کدگذاری می‌شود؛ داده مکانی منتقل نمی‌شود |
| نام‌گذاری | قالب‌های `{name}` `{n}` `{i}` `{w}` `{h}` `{ext}` |
| آفلاین | پس از اولین بازدید، بدون اینترنت هم کار می‌کند (Service Worker) |
| تم و رنگ برند | ۸ پالت رنگی + حالت روشن و تاریک، ذخیره‌شده در `localStorage` |

## حریم خصوصی

- **بدون آپلود.** تمام پردازش داخل مرورگر انجام می‌شود.
- **بدون درخواست خارجی.** فونت، کتابخانه‌ها و اسکریپت‌ها همگی محلی‌اند.
- **بدون ذخیره‌سازی، بدون کوکی، بدون آنالیز، بدون حساب کاربری.**

## اجرای محلی

هیچ build step یا سروری لازم نیست:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## ساختار

```
.
├── index.html          # صفحه اصلی + JSON-LD
├── style.css           # دیزاین‌سیستم (توکن‌محور، RTL، واکنش‌گرا)
├── app.js              # موتور پردازش، رابط کاربری، سازنده ZIP
├── sw.js               # Service Worker (کار آفلاین)
├── manifest.json       # PWA manifest
├── robots.txt
├── sitemap.xml
├── 404.html
├── fonts/
│   └── Vazirmatn.woff2 # فونت متغیر، خودمیزبان
├── icons/
│   ├── icon.svg
│   └── icon-maskable.svg
└── vendor/
    ├── heic2any.min.js # رمزگشایی HEIC (MIT)
    └── pica.min.js     # بازنمونه‌برداری با کیفیت بالا (MIT)
```

## استک

- [heic2any](https://github.com/catdad-express/heic2any) — رمزگشایی HEIC/HEIF (MIT)
- [pica](https://github.com/nodeca/pica) — بازنمونه‌برداری تصویر (MIT)
- [Vazirmatn](https://github.com/rastikerdar/vazirmatn) — فونت فارسی متغیر (OFL)
- Canvas API — کدگذاری، فیلتر و شارپ الگوریتمی
- سازنده ZIP داخلی (روش store، بدون وابستگی)
